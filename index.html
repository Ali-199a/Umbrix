System Design

Security architecture.

Hover each layer to see how the pipeline works. Every stage is isolated — compromise one layer and the others remain intact.

① Key Derivation Layer SHA-256 KDF
Password → SHA-256 → 256-bit symmetric key. This operation is one-way: the key cannot be reversed to reveal your password. The derived key lives in memory only for the duration of the operation, then is discarded.
② AES-256 Encryption Layer EAX Mode · AEAD
The derived key encrypts your plaintext using AES-256-EAX — an authenticated encryption mode. A random nonce is generated per operation. The output is ciphertext + authentication tag. Any modification to the ciphertext causes tag verification to fail.
③ Steganography Layer LSB Image Injection
The binary-encoded ciphertext is distributed across the least-significant bits of RGB pixel channels in the carrier image. The perceptual change per pixel is ≤1/255 — invisible. A length header is prepended so the decoder knows how many bits to extract.
④ File Output Layer Local Disk Write
The stego-image is written to your local file system in its original format. No metadata is added. No file is transmitted. The only copy exists on your hardware. The original carrier and plaintext are never stored.
